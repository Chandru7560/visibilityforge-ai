# Product walkthrough recording script

**Maximum:** 5 minutes. **Status:** Not recorded; no video URL is available.

## Before recording

- Wait for a verified public application URL and working authorized account.
- Use only real records and screenshots; redact personal data and credentials.
- Ensure any research source and technical-audit target are authorized.
- If an item is empty or unavailable, say so rather than staging a fake result.

## Suggested timing

1. **0:00–0:30 — Context:** state the verified live URL and explain that the workspace records evidence; it does not automatically query search engines or assistants.
2. **0:30–1:20 — Research Hub:** show a real, sourced question and distinguish an unverified idea from a verified question.
3. **1:20–2:00 — Measurement:** open a real saved observation, showing the engine/profile, market, collection method, date, evidence, and any unavailable result.
4. **2:00–2:50 — Technical audit:** show an authorized audit and one observed finding with its evidence and validation state. Do not present proposed recommendations as detected issues.
5. **2:50–3:35 — Content Studio:** show a real saved draft, its sources, checklist, and draft status; do not call it published.
6. **3:35–4:10 — Citation planner:** show an actual researched opportunity and its relevance evidence, or explain that none is recorded.
7. **4:10–4:45 — Reports/export:** show a stored report or an actual CSV export, explain its sample size and limitations.
8. **4:45–5:00 — Close:** summarize what was measured and what remains manual or unavailable.

Use the actual deployed URL only after it has been tested. Do not imply this script is a recorded or uploaded video.
